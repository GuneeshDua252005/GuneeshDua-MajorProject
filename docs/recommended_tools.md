# Recommended application tools for creating a strong 8th-sem major project package

## 1. For coding and execution

- **Visual Studio Code**
  - best for writing, debugging, and presenting a clean Python project
  - easy terminal access
  - easy extension support

- **Python 3.10 or 3.11**
  - recommended for Windows compatibility with TensorFlow

- **Streamlit**
  - best free Python-only UI layer for a single-file major project
  - avoids separate frontend and backend complexity

## 2. For free AI integration

- **Hugging Face**
  - recommended free API ecosystem
  - simple token creation
  - wide choice of public models
  - good alternative when paid APIs are not suitable

- **Why not use paid APIs as the main base**
  - OpenAI generally requires billing for reliable API use
  - Spotify is good for search and metadata but not ideal as the core emotional reasoning engine
  - a free-first academic submission is easier to reproduce with Hugging Face plus local fallback logic

## 3. For datasets

- **Hugging Face Datasets**
  - useful for sampled image emotion datasets
  - easy to test with small subsets

- **Manual ZIP datasets**
  - good for class-wise folder import
  - simple for viva demonstration

## 4. For documentation and paper writing

- **Microsoft Word**
  - best for final IEEE-style formatting if available
  - easiest for faculty sharing and printing

- **LibreOffice Writer**
  - good free alternative for editing `.docx`

- **Markdown + Word export**
  - best development workflow
  - write the content in Markdown, then refine in Word

## 5. For diagrams and flowcharts

- **draw.io / diagrams.net**
  - free and very good for system architecture diagrams and flowcharts

- **PowerPoint**
  - helpful for project block diagrams and viva presentation slides

## 6. For APK conversion trick

- **Chrome Add to Home Screen**
  - easiest free install-like experience for a Streamlit app

- **Android Studio WebView wrapper**
  - free workaround when a native APK-like deliverable is required
  - easier than packaging a full Python runtime

## 7. Best practical tool stack for this project

If the goal is a clean, presentable, and reproducible major project, the best free stack is:

1. VS Code
2. Python 3.10/3.11
3. Streamlit
4. Hugging Face token-based optional inference
5. local CSV logging
6. Markdown + Word paper workflow
7. draw.io for diagrams

This combination is realistic for student hardware, easy to explain in viva, and strong enough for a polished final submission.
