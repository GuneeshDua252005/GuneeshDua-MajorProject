## Free API guide for Hugging Face integration

This project is designed to run without any paid API. The free upgrade path is Hugging Face because:

- it supports public inference models
- it uses a simple personal access token
- it can be used only when needed
- the application still works offline with fallback logic if the API is unavailable

### Why not OpenAI or Spotify for the base submission

- OpenAI usually requires billing for production-grade API access.
- Spotify Web API is good for metadata and search, but it is not ideal as the primary emotional reasoning engine.
- For a major project demo, free-first and reproducible execution is more practical.

### Create a free Hugging Face account

1. Open: https://huggingface.co/join
2. Sign up with email or continue with GitHub.
3. Verify your email.

### Generate a free token

1. Sign in to Hugging Face.
2. Open: https://huggingface.co/settings/tokens
3. Click **New token**.
4. Give it a name such as `cei-major-project-token`.
5. Choose a read/inference-friendly scope if prompted.
6. Copy the generated token.

### Use the token in this project

For Windows PowerShell:

```powershell
$env:HUGGINGFACE_API_TOKEN="your_token_here"
```

For CMD:

```cmd
set HUGGINGFACE_API_TOKEN=your_token_here
```

For Linux/macOS:

```bash
export HUGGINGFACE_API_TOKEN="your_token_here"
```

You can also paste the token directly into the Streamlit sidebar while testing.

### Recommended free models

Emotion classification:

- `j-hartmann/emotion-english-distilroberta-base`

Reflective question generation:

- `google/flan-t5-base`

### Important note

The token is not generated by this application. Hugging Face creates it inside the user account dashboard for security reasons. The app only consumes the token after the user provides it.

### If the free API is rate-limited

The app automatically falls back to:

- local lexicon-based emotion analysis
- template-based reflective questions
- local recommendation logic

This means the project remains demonstrable even without internet access or when the free API is temporarily unavailable.
