# Paper bundle

This folder contains the academic write-up package for the project.

## Files

- `ieee_research_paper.md` - long-form IEEE-style draft
- `literature_matrix.md` - comparison matrix for the collected papers
- `generate_docx.py` - script to generate the Word document
- `Cognitive_Emotion_Intelligence_Adaptive_Lifestyle_System_IEEE_Paper.docx` - generated Word file

## Regenerate the Word file

From the repository root:

```bash
python3 paper/generate_docx.py
```

This requires `python-docx`, which is already listed in `requirements.txt`.
