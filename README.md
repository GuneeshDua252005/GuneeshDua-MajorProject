# GuneeshDua-MajorProject

Cognitive Emotional Intelligence, reinforcement learning style recommendation, Digital Emotional Twin logging, and multimodal AI fusion with ethical monitoring.

## Run in VS Code

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Python 3.11.9 is recommended on Windows because PyTorch wheels are reliably available. The application is PyTorch-only and uses a `.pth` checkpoint when you train a model.

## Main files

- `app.py` - single-file Streamlit application
- `requirements.txt` - minimal required packages
- `models/` - optional PyTorch `.pth` checkpoints generated by training
- `dataset/` - optional local image dataset for EfficientNetV2-S training
