# GuneeshDua-MajorProject

CEI-ALOS Streamlit prototype for cognitive emotional intelligence, reinforcement-style recommendation, digital emotional twin logging, and multi-modal AI fusion.

## What is in this branch

This branch adds a single-file `app.py` that includes:

- Multi-modal mood intake: face image, emoji, voice transcript, and free text
- Transfer-learning CNN flow using MobileNetV2
- Evaluation metrics: precision, recall, F1, confusion matrix, ROC-AUC when available
- Grad-CAM explainability for image predictions
- History-aware recommendation with repetition avoidance and feedback tracking
- Spotify search integration and OpenAI chat integration
- CSV-based Digital Emotional Twin logging
- Automatic public dataset download and train/val export for openly accessible Hugging Face image datasets
- A structured 100+ entry resource catalog with CSV export

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Environment variables

- `SPOTIPY_CLIENT_SECRET`
- `OPENAI_MODEL` (optional override)

## Public dataset automation

The app can download and reformat public emotion image datasets from Hugging Face into a local folder structure like:

```text
dataset/<dataset-name>/
  train/<class-name>/*.jpg
  val/<class-name>/*.jpg
```

This is intended for open, no-auth datasets such as public FER-style image datasets. Some academic datasets (for example RAF-DB or CK+) often require manual approval or separate licensing, so they are mentioned as manual options rather than bundled download presets.
